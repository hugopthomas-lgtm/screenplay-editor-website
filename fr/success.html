Bienvenue dans Pro !

Votre passage à Pro est enregistré. Toutes les fonctions Pro sont débloquées.

Et maintenant ?

Retournez sur votre document Google Docs et rechargez le panneau Screenplay Editor pour activer vos fonctions Pro.

Si le panneau est déjà ouvert, fermez-le et rouvrez-le depuis le menu Extensions.

1
Retournez sur votre document Google Docs
2
Ouvrez Extensions → Screenplay Editor → Ouvrir le panneau
3
Votre statut Pro apparaîtra tout seul. Bonne écriture !
