Modèle de scénario gratuit pour Google Docs

Ce modèle est fait pour ceux qui débutent, les étudiants et les auteurs indépendants qui veulent écrire un scénario dans Google Docs sans régler la mise en forme à la main.

Le format du scénario obéit à des règles précises : marges, retraits, espacements, placement de chaque élément. Tout régler soi-même dans Google Docs prend du temps et se rate facilement. Un modèle déjà réglé règle le problème : vous écrivez tout de suite.

Ce que contient ce modèle

  • Les bonnes marges (3,8 cm à gauche, 2,5 cm ailleurs)
  • La police Courier 12 déjà réglée
  • Le format des titres de séquence (INT./EXT., en majuscules)
  • Les espacements de l’action, des personnages et des dialogues
  • Une page de titre
  • Une scène d’exemple qui montre la structure

Pourquoi la mise en forme casse dans Google Docs

Google Docs n’a pas été fait pour le scénario. Il n’a pas de styles dédiés, il faut donc régler les marges et les retraits à la main pour chaque type d’élément.

Les problèmes que les auteurs rencontrent :

  • La dérive du format à la main Après une vingtaine de pages à déplacer la règle, les marges ne concordent plus.
  • Les ennuis de copier-coller Coller du texte venu d’ailleurs ramène souvent une mise en forme dont on ne veut pas.
  • Les réécritures Modifier et réécrire casse les espacements que vous aviez soigneusement posés.

Partir d’un modèle aide, parce que les réglages sont bons dès le départ. Sur un projet long, un module de mise en forme tient la constance à votre place.

Ce que Screenplay Editor apporte

Screenplay Editor est un module Google Docs qui applique la mise en forme pendant que vous tapez. Il est facultatif : ce modèle fonctionne tout seul.

  • Il pose les bonnes marges et les bons retraits tout seul
  • Il reconnaît les éléments (titre de séquence, dialogue, action)
  • Il retient les noms de personnage et les complète
  • Il exporte en PDF, et en Final Draft (.fdx) avec Pro
