Screenplay Editor face à WriterSolo

Dernière mise à jour : February 2026

Deux outils de scénario utilisables gratuitement, deux philosophies. WriterSolo est une application web indépendante. Screenplay Editor vit dans Google Docs. La vraie question : où voulez-vous que vos scénarios habitent ?

WriterSolo fonctionne au prix libre, ce qui est honnête et généreux. Vous avez un environnement de scénario complet dans le navigateur. Ça marche bien. Rien à redire sur l’outil.

La différence porte sur la propriété et la méthode. Avec WriterSolo, vos scénarios vivent sur leur plateforme. Avec Screenplay Editor, tout reste dans votre Google Drive. Les fichiers sont à vous, les sauvegardes aussi. Si vous arrêtez d’utiliser le module, vos documents sont toujours là.

Quand choisir WriterSolo

WriterSolo est un bon choix pour certaines façons de travailler.

  • Vous voulez une application web indépendante, dédiée au scénario
  • Vous n’utilisez pas Google Docs et vous n’avez pas envie de commencer
  • Vous aimez leur interface et leur environnement d’écriture
  • Vous voulez l’export .fdx tout de suite
  • Vous préférez un outil conçu pour le scénario plutôt qu’un module

Quand choisir Screenplay Editor

Screenplay Editor convient mieux si ces points comptent pour vous.

  • Vous voulez vos scénarios dans Google Drive, des fichiers qui vous appartiennent
  • Vous écrivez à plusieurs en direct, dans Google Docs
  • Vous vivez déjà dans l’écosystème Google et vous ne voulez pas d’une plateforme de plus
  • Vous voulez l’historique intégré : Google Docs garde chaque modification
  • Vous partagez un scénario en partageant un lien Google Docs, sans export
